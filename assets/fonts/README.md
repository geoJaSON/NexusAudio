# Fonts

NEXUS//AUDIO renders best with these two bundled fonts. The app runs without
them (it falls back to egui's built-in monospace), but the CRT look needs them.

Drop these files here, with these exact names:

- `ShareTechMono-Regular.ttf` — body text
  https://fonts.google.com/specimen/Share+Tech+Mono
- `VT323-Regular.ttf` — the NEXUS//AUDIO logo
  https://fonts.google.com/specimen/VT323

Both are SIL Open Font License.
